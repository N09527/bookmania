## 1. 做了什麼

### 1.1 翻頁動畫的做法（兩個閱讀器共用，新 package `yokai.pageturn`）

- **流程**：
  1. 用 `PixelCopy` 複製目前畫面上閱讀區域的像素。
  2. 把複本畫在一個疊在視窗上方的獨立畫面層（`SurfaceView`，`setZOrderOnTop`）。
  3. 閱讀器照原本的方式換頁（文字閱讀器：殼層的 `next()`／`prev()`；漫畫閱讀器：`ViewPager.setCurrentItem(…, false)`），換頁發生在複本底下，看不到。
  4. 等視窗畫出新頁後，複本捲起或滑開，露出新頁；結束後疊層移除。
- **為什麼用獨立的畫面層**：`PixelCopy` 只複製視窗本身，不含這個疊層，所以舊頁還蓋在上面時就能再複製新頁。雙欄往後翻時，翻起那一頁的背面要帶著新頁的內容（見下），需要新頁的複本；滑動也用新頁的複本，讓兩頁一起移動。
- **捲曲的幾何**：把紙的一角拉到手指位置、平平摺過去的模型。
  - 摺線是「角」與「拉到的位置」連線的垂直平分線。摺線靠角這一側的紙被掀起；掀起的部分以摺線為鏡面翻過去，就是露出背面的那一片（以下稱頁背）。
  - 角從原位移到它對「裝訂線」的鏡像位置；移到終點時，摺線就是裝訂線，整頁翻到另一側。
  - 途中角會稍微抬高，摺線因此是斜的，看起來是從角落掀起。
  - 幾何是純 Kotlin，在 JVM 上做了單元測試（`CurlGeometryTest`，10 項）：紙的面積不變、裝訂線全程不被掀起、角永遠在手指位置、頁背上的內容跟著頁背移動、左開與右開互為鏡像等。
- **方向**：
  - 左翻（橫書、左開）：從右下角掀起，往左翻。
  - 右翻（直書、右開）：從左下角掀起，往右翻。
  - 漫畫閱讀器的直向翻頁模式：從下緣（右下角）往上翻，以上緣為軸。
  - 往前翻：同一個動作倒著播放，前一頁從另一側翻回來蓋上。
- **雙欄（文字）與雙頁（漫畫）**：以中線為軸只翻一頁。左開時翻起右半頁，頁背帶著新的左頁落到左半；右開相反。單頁時，頁背是紙的顏色（閱讀器的背景色）加上漸層陰影。
- **滑動**：舊頁往一側移出、新頁從另一側移入（與漫畫閱讀器的頁面轉場同方向）。
- **時間**：捲曲 500 毫秒、滑動 260 毫秒，都跟隨系統的「動畫時間比例」；系統關閉動畫時不播放，直接換頁。
- **安全**：只讀取畫面像素，不執行書中的任何內容，不連網；沒有新增第三方元件。

### 1.2 文字閱讀器

- **設定**：排版面板「版面」分頁最下方新增「翻頁動畫」，選項是 無／滑動／捲曲。這個設定所有書共用，不受面板上方「套用範圍」（全部書籍／這部作品／這個檔案）影響，面板上有說明。預設「滑動」【決定，見 1.6 第 1 項】。
- **哪些翻頁會播放**：點擊、滑動手勢、按鍵（音量鍵、Page Up／Down、方向鍵）翻頁。目錄、全書進度滑桿、連結的跳轉不播放。選單或排版面板開著時不播放，因為疊層在視窗上方，會蓋住選單。
- **跨章節檔的翻頁**：舊頁最多保留 0.7 秒，等下一個章節檔排版完成：
  - 時間內完成：播放動畫。
  - 超過時間：撤下舊頁，顯示原本的排版中畫面，不播放動畫。這是為了不讓畫面停住太久。
- **連續快速翻頁**：還在準備或播放中的翻頁會立刻結束，下一次翻頁接著做；每一次按鍵都算數。

### 1.3 漫畫（圖片）閱讀器

- **新增開關「捲曲翻頁」**（預設關閉），放在兩個地方：
  - 設定 > 閱讀：「翻頁轉場動畫」的下一項。
  - 閱讀器內的設定面板：翻頁模式的設定，同樣在「翻頁轉場動畫」的下一項。
- **三種選擇的對應**：
  - 無：兩個開關都關。
  - 滑動：只開「翻頁轉場動畫」（既有開關，預設開）。
  - 捲曲：開「捲曲翻頁」。
- **適用範圍**：翻頁模式（左至右、右至左、直向）的點擊與按鍵翻頁。
  - 雙頁模式：以中線翻一頁。
  - 長條（webtoon）模式：不受影響。
  - 用手指滑動：仍是既有的拖動頁面【決定，見 1.6 第 2 項】。
  - 選單開著時：照既有行為。
- **開關關閉時**：既有程式碼的行為完全沒有改變。改動只是在 `moveRight`／`moveLeft` 換頁前，先問捲曲元件要不要處理（第 1.5 節）。
- **頁背的顏色**：閱讀器的背景色（設定的白／灰／黑等）。

### 1.4 文字閱讀器的章節面板

- **開啟**：工具列新增「章節」按鈕（清單圖示），在目錄按鈕左邊。
- **列出的章節**：與漫畫閱讀器的章節面板相同，篩選與排序都一樣（`ChapterSort.getChaptersSorted(…, filterForReader = true)`），也沿用同一個清單項目的版面。目前的章節以粗斜體顯示，開啟時捲到目前的章節。
- **操作**【決定，見 1.6 第 7 項】：
  - 點一下：先存下目前的閱讀位置，再開啟所選章節。開在哪個閱讀器由既有的導向決定：文字書開在文字閱讀器，圖片章節開在漫畫閱讀器，EPUB 依判定結果。
  - 長按：標為已讀／未讀。
  - 書籤按鈕：加上／取消書籤。
  - 這三項操作與漫畫閱讀器的章節面板相同。
- **錯誤畫面**：章節是哪一章已經知道時（例如受 DRM 保護的檔案），錯誤畫面的工具列也有這個按鈕，可以改開同一作品的其他檔案。

### 1.6 我做的決定（都可以改）

1. **文字閱讀器預設「滑動」**：與漫畫閱讀器的預設（翻頁轉場動畫開）一致。改成預設「無」只要改一個常數。
2. **漫畫閱讀器的捲曲只用在點擊與按鍵**：用手指滑動仍是既有的拖動頁面（`ViewPager` 跟著手指移動）。若要用手指滑動時也捲曲，需要改動既有的拖動與縮放處理，上游改動會大很多。
3. **漫畫閱讀器用新增一個開關**，而不是把既有開關改成三選一的清單，以減少對上游介面檔案的修改。
4. **文字閱讀器的設定所有書共用**，不做三層覆寫；放在排版面板的「版面」分頁。
5. **單頁的頁背只畫紙色加陰影**，不畫透出的反面文字。
6. **跨章節檔的翻頁最多保留舊頁 0.7 秒**（見 1.2）。
7. **章節面板的操作與漫畫閱讀器的章節面板相同**（點一下開啟、長按切換已讀、書籤按鈕）。你只要求「列出同一作品的其他檔案」；長按與書籤是既有面板本來就有的操作，我沿用以維持一致。如果不要，可以拿掉。
8. **選單或面板開著時不播放動畫**（見 1.2）。
