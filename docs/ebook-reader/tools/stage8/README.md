# 階段 8 的檢查：作品頁字串、排版數值的輸入欄、雙欄的邊距上限

這些腳本只用於測試，不屬於 App。需要第 3～7 階段資料夾的輔助程式（同一個 `tools/` 之下），以及模擬器上的 debug App。

| 步驟 | 內容 |
|---|---|
| `strings` | 探索 > 本機來源 >「橫排測試書 EPUB」的作品頁：簡介標題是「內容簡介」（不再是「關於此日漫」），右側的章數是「共 N 冊」。 |
| `fields` | 排版面板的輸入欄。單欄：字級、行距、字距、首行縮排、段落間距與上下左右邊距，各輸入一個值後按 Enter（輸入法的「完成」）：存入的值與書頁上的樣式（字級、行高、字距、縮排、段落下方間距，以及頁框的位置與大小）都符合。點輸入欄時鍵盤出現、輸入欄移到鍵盤上方、書頁不重新排版；按完成後鍵盤收起。超出範圍的值（字級 60）不套用，並顯示可輸入的範圍；離開輸入欄後恢復原值。首行縮排與段落間距在「依書籍」時沒有輸入欄。雙欄：用輸入欄改字級後，兩欄各在自己的頁面上，書頁裡沒有取得焦點的元素。 |
| `margins` | 雙欄、直向（畫面寬 412 dp）：殼層回報上限 132（412 − 2 × 120 − 40），面板顯示「雙欄時，左右邊距合計最多 132 dp」。左邊距輸入 120 不套用（右 20 時可輸入 0～112），112 套用後仍是兩欄、每欄 120。右邊距滑桿拉到底停在上限。左邊距來回改動時一直是兩欄。已存的邊距超過上限（80 + 90）：兩欄，邊距按比例縮小為 62 + 70，面板說明會縮小。橫向：上限超過 120 + 120，沒有說明、不縮小。單欄：沒有上限，左邊距可輸入 120。 |
| `cleanup` | 排版設定恢復預設，直向。 |

```bash
ADB=/path/to/adb python3 -I check_stage8.py strings fields margins cleanup
```

結果在 `out/results.jsonl`（每個檢查一行 JSON），截圖在 `out/shots/`。

輸入欄的找法：輸入欄是 `EditText`，它的說明文字（項目名稱）在子節點上，所以腳本找「與項目名稱同一列的 `EditText`」。項目名稱只認面板的 `TextView`；書頁本身的文字節點是 `View`，可能有同樣的字。
