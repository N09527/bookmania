# 階段 5.5 的驗證腳本（翻頁動畫、文字閱讀器章節面板）

這些腳本只用於測試，不屬於 App。

需求與 `../stage5/README.md` 相同（`adb`、Python 3、已安裝 debug APK 並放好測試書的模擬器、App 語言為繁體中文、螢幕 1080×1920），另外需要本機的 `ffmpeg`、`ffprobe`、Pillow 與 numpy。`check_pageturn.py` 會用到 `../stage5/check_stage5.py`（以及它用到的 `../stage3/drive.py`、`../stage4/verify_columns.py`）。

| 檔案 | 用途 |
|---|---|
| `check_pageturn.py` | 模擬器上的各項檢查，結果逐行寫入 `out/results.jsonl`；每次翻頁的錄影、逐格畫面與分析在 `out/rec/<名稱>/`，挑出的畫面並排成 `out/shots/<名稱>-frames.png`。步驟見檔案開頭的說明 |
| `run-all.sh` | 依序執行本階段的全部檢查。`./run-all.sh 7` 從第 7 項開始；`STEPS="3 5 7-9" ./run-all.sh` 只跑指定的項目 |

做法：

- 每次翻頁用模擬器的 `screenrecord` 錄下（畫面縮為一半），按鍵（Page Down／Page Up）在錄影開始後送出。翻頁前、翻頁後各截一張圖。
- 逐格分析：畫面切成 20×20 像素的格子，只看「翻頁前後兩頁內容不同」的格子；每一格判定為「舊頁」（與翻頁前相同）、「新頁」（與翻頁後相同）或兩者皆非（捲起的頁背、陰影、移動中的頁）。
  - 有動畫：至少兩格畫面同時有舊頁與新頁的部分。「無」則不應有這種畫面。
  - 捲曲的方向：第一張同時有新舊頁的畫面中，新頁出現在哪一半（往後翻時新頁先出現在右半／左半，直向翻頁模式先出現在下半）。
  - 雙欄（雙頁）以中線翻一頁：翻頁前半段，新頁只出現在被翻起的那一半；另一半是捲起的頁背（帶著新頁的內容，但位置與角度還不是最後的樣子）。
  - 翻頁後畫面不再變化（沒有留下疊層）。
- 錄影的時間點受模擬器速度影響（這部模擬器沒有硬體加速，畫面更新很慢），錄到的格數比實機少；判定只用格子的分類，不依賴格數。
- 章節面板：在作品「橫排測試書 EPUB」的資料夾放入一個圖片章節（`add_chapter`，複製測試用的 CBZ），在作品頁下拉重新整理後，檢查面板列出的章節、長按切換已讀、書籤按鈕、點選文字章節與圖片章節分別開在哪個閱讀器，以及離開的章節有沒有存下位置。這個作品因此多了一個章節（第 6 階段回歸時要注意）。
- 設定：文字閱讀器排版面板「版面」分頁的「翻頁動畫」，以及設定 > 閱讀的「捲曲翻頁」開關。
